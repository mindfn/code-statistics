# Reflection Capsules

Feature 或 milestone 完成时，在本目录新增一份
`YYYY-MM-DD-{topic}-capsule.md`。胶囊必须包含以下六个章节：

1. Context
2. What Worked
3. What Failed
4. Trigger Missed
5. Doc Links
6. Rule Update Target

模板：

```markdown
---
capsule_id: YYYY-MM-DD-{topic}
feature_ids: [Fxxx]
topics: [...]
doc_kind: reflection
created: YYYY-MM-DD
---

# {Feature} Reflection Capsule

## Context

## What Worked

## What Failed

## Trigger Missed

## Doc Links

## Rule Update Target
```
