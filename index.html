PR 代码变更统计

配置数据仅保存在当前浏览器

Token、用户和仓库配置保存在浏览器 localStorage，不会上传到本工具的服务器；Token 仅通过请求头直接发送给 GitHub / GitCode API，导出的 CSV 不包含 Token。

通过 http(s)（含 GitHub Pages）使用时，已合入 PR 的代码量、Comments 和 Approve 会缓存在本机 IndexedDB；直接双击 file:// 使用时只缓存于当前页面内存。

清除本网站的浏览器数据会同时清除全部配置和 PR 缓存，请勿在不受信任的公共设备上保存 Token。

GitHub Token

需要 repo 权限（私有仓库）或 public_repo 权限（公开仓库）。Fine-grained Token 需要 Pull requests 只读权限。

GitCode Token

仓库管理

添加需要统计的 GitHub / GitCode 仓库。所有用户的 PR 将从这些仓库中查询。

网络与代理

本工具沿用操作系统或浏览器的代理设置，不提供应用内代理配置。

请确保您的浏览器可以正常访问以下地址：

  • https://api.github.com
  • https://api.gitcode.com

如果在公司网络环境下无法访问，请配置系统代理或浏览器代理后重试。
